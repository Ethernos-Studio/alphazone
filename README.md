# ALPHA ZONE — 此处无未来

独立游戏世界观概念宣传站。基于提供的 EPUN / DeWorld / ALPHA ZONE 虚构设定制作。

## 打开网站

**最简单：双击 `index.html`。** 请保留同目录的 CSS、JavaScript 和 `assets` 文件夹。页面不依赖 CDN、外部图片、在线字体、后端或安装依赖。

如已安装 Bun，也可在项目目录运行：

```sh
bun scripts/serve.js
```

然后访问 **http://127.0.0.1:4173**。默认只监听本机地址，不向公网发布。通过 `PORT` 环境变量可修改端口。

## 已实现

- 原创巨幅字标、AZ 标志、程序化冰雪山谷与废弃雷达站；轻量 Canvas 风雪。
- 桌面、平板、手机响应式布局与移动导航。
- 4 个可选封锁区节点，位置说明与关联战档跳转。
- 5 个阶段、21 条完整事件，包含同期新闻播报与原稿中的列表详情。
- 事件前后浏览、记录深链接、复制记录链接、完整 UTF-8 文本档案下载。
- 「雪鸦」5 档广播调谐器、键盘方向键调谐、音量和环境音开关。
- 仅在用户点击后启用 Web Audio 环境音；切到后台自动停止，回到页面不自动播放。
- 跳过导航、语义化按钮、可见焦点、选中状态、减少动画偏好。

**电台声音是本地合成的噪声环境音，不是真人/AI 语音播报。频率为界面模拟值，并非新增游戏设定。**

## 二次修改

- 配色：编辑 `styles.css` 顶部 `:root` 变量。
- 年表、新闻及地图说明：编辑 `story-data.js`。
- 重新生成文字档案 / 地图 / 标志：`bun scripts/generate-assets.js`。
- 重新生成雪原：`uv run --with pillow --with numpy python scripts/generate_landscape.py`。
- 修改首屏文案、网站区块：编辑 `index.html`。

## 原创素材与字体

视觉素材全部在本地由代码生成，**未调用 AI 生图、未使用图库照片**。

雪原采用多层噪声三维高度场、法线光照、体素空间可见性、雾化深度以及 Pillow 投影建筑绘制。SVG 地图包含原创等高线和示意边界。标题字体为 Big Shoulders Bold，拉丁正文为 Instrument Sans Regular，均附 SIL Open Font License。中文由设备上的 Microsoft YaHei / PingFang SC 等系统字体渲染，不再分发商业字体文件。

## 设定与发布边界

- 全部战争、组织、新闻为虚构。网站在页尾、档案下载及电台中有明确提示。
- 保留原稿中的事件日期、数值和新闻，不擅自“修正”作者设定；新增小标题与宣传文案用于阅读组织，不取代原始记录。
- 原稿内部有待作者后续校对之处：9 月 24 日广播将当天称为 8 月 5 日核爆的三周年；核弹分项与“其余19枚”之和与总数不一致；制裁遭否决但同时只交代弃权；辐射单位与“8倍”表述未统一。页面保留这些内容并注明未改写。
- 地图是世界观示意图，并非真实军事或精确地理资料。地下井网位置未被设定为真实已知坐标。
- 未虚构商店地址、试玩下载、发行日期、预约人数或尚未确认的游戏玩法。无用户信息收集与追踪。
- 本地 `file://` 或 localhost 链接仅在相应设备/服务器可访问。要公开分享，请将静态文件部署到自己的服务器；本次未部署公网。
- 本地完整副本可离线打开；未实现面向已托管网页的 Service Worker 离线缓存。
